# Практическая работа №5. Классификатор и анализ метрик

Вариант: C


Датасет: Mammography (OpenML, `fetch_openml('mammography', version=1)`), около 11 тысяч строк,
6 числовых признаков, доля положительного класса около 2,3% (дисбаланс ≈ 1:42).
Копия лежит в `data/raw/mammography.csv`.

## Что сделано

- Базовая модель: логистическая регрессия без коррекции дисбаланса
- Два метода коррекции: class_weight="balanced" и SMOTE (imbalanced-learn)
- Одинаковая схема валидации для всех: RepeatedStratifiedKFold, 5 фолдов × 3 повтора
- Парное сравнение с базовой моделью (критерий Вилкоксона по фолдам)
- Порог классификации выбран на out-of-fold предсказаниях train по F2 (recall важнее precision)
- Итоговая оценка на test: precision, recall, F1, F2, ROC-AUC, PR-AUC и матрицы ошибок
