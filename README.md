## Структура репозитория

- `prXX-xxx.../` - директория под номером СРС. В каждой приложен РИДМИ с деталями

- `pr01-env-setup/` — Практическая работа №1. Настройка окружения и первый notebook
- `pr02-eda/` — Практическая работа №2. Разведочный анализ данных (EDA)
- `pr03-pipeline/` — Практическая работа №3. Сборка пайплайна предобработки
- `pr04-regression/` — Практическая работа №4. Регрессионная модель
- `pr05-imbalance/` — Практическая работа №5. Классификатор и анализ метрик
- `pr06-text-classification/` — Практическая работа №6. Классификация текстов с использованием TF-IDF, Naive Bayes и Logistic Regression
- `pr07-random-forest/` — Практическая работа №7. Случайный лес, сравнение важности признаков и интерпретация модели с помощью SHAP
- `pr08-gradient-boosting/` — Практическая работа №8. Градиентный бустинг: сравнение XGBoost, LightGBM, CatBoost, ранняя остановка, категориальные признаки
- `pr09-svm/` — Практическая работа №9. Метод опорных векторов: LinearSVC vs RBF, GridSearch C/gamma, high-dimensional TF-IDF, scaling analysis
- `pr10/` — Практическая работа №10. Кластеризация и сегментация: K-Means, DBSCAN, иерархическая кластеризация


## Как запустить любую работу

1. Клонировать репозиторий
2. Создать и активировать виртуальное окружение:
```
   python -m venv .venv
   .venv\Scripts\activate
```
3. Установить зависимости:
```
   pip install -r requirements.txt
```
4. Открыть нужный `.ipynb` в папке `prXX-.../notebooks/`, выбрать kernel `.venv`, выполнить `Run All`

Для ПР-10 описание уровней, датасета и результатов см. в [локальном README](pr10/README.md); готовые ноутбуки находятся в `pr10/notebooks/`, данные — в `pr10/raw/`. Исходный шаблон сохранён отдельно в `pr10/normtemplate/`.
